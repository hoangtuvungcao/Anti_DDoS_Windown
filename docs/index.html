KIẾN TRÚC NHÂN MẠNG

Ma Trận Phòng Thủ 5 Lớp Độc Lập

Mọi gói tin độc hại từ Internet sẽ bị phân tích và triệt tiêu ngay lập tức trước khi chạm vào cổng ứng dụng máy chủ của bạn.

LAYER 0

IP & Geo-IP Filter

Whitelist ưu tiên, blacklist tự động khóa và tra cứu dải IPv4 Việt Nam bằng binary search khi Geo-IP được bật.

LAYER 1

RFC Packet Scrubbing

Hủy bỏ các gói tin TCP/UDP bị dị dạng, cờ TCP không hợp lệ (XMAS, NULL scan), và triệt tiêu đòn phản xạ khuếch đại DNS 53, NTP 123, SSDP 1900.

LAYER 2

Socket Auto-Discovery

Tự động quét và phát hiện các cổng đang lắng nghe thực tế trên Windows (1-65535). Mọi gói tin gửi vào cổng đóng sẽ bị hủy tại chỗ, bảo vệ CPU máy chủ.

LAYER 3

TCP Shield & Proxy

Theo dõi trạng thái SYN/ACK, giới hạn tốc độ theo IP/subnet và dọn kết nối treo để giảm SYN Flood, ACK Flood và Slowloris.

LAYER 4

UDP & Game Query DPI

Phân tích sâu chữ ký gói tin (DPI), kiểm soát Token Bucket 120 PPS/luồng, chống bão truy vấn Server List (A2S, SAMP, FiveM query flood) và chống Carpet Bombing /24.

TÀI LIỆU HƯỚNG DẪN

Bộ Lệnh & Tài Liệu Vận Hành Toàn Diện

Hướng dẫn chi tiết từ cách chạy trực tiếp, cài đặt dịch vụ ngầm 24/7 đến tùy biến file cấu hình.

Mục Lục Nhanh
  • 1. Chạy Trực Tiếp
  • 2. Dịch Vụ Ngầm 24/7
  • 3. Bộ Lệnh Quản Trị
  • 4. Web SOC Dashboard
  • 5. Trình Tạo Config.json

1. Cách Chạy Trực Tiếp (Console & Web Dashboard)

Dành cho kiểm tra nhanh trạng thái lưu lượng và hiệu năng máy chủ khi đang kết nối Remote Desktop:

  1. Giải nén thư mục WAF-Shield-Deploy/ vào ổ đĩa trên VPS (ví dụ C:\WAF-Shield).
  2. Nhấp đúp chuột vào file CHAY_WAF.bat (hoặc chuột phải chọn Run as Administrator).
  3. Bảng điều khiển Console sẽ hiển thị thông số PPS, Bps, trạng thái ma trận bảo vệ.
  4. Mở trình duyệt truy cập http://localhost:8080 để vào Web SOC Dashboard.

2. Cài Đặt Chạy Ngầm Tự Động 24/7 (Windows Service)

WAF sẽ tự động khởi động cùng hệ điều hành Windows ngay khi VPS bật nguồn mà không cần bạn phải đăng nhập Remote Desktop:

CÁC BƯỚC CÀI ĐẶT DỊCH VỤ 
Bước 1: Chuột phải vào 'CAI_DAT_SERVICE.bat' -> Chọn 'Run as Administrator'
Bước 2: Chuột phải vào 'BAT_SERVICE.bat'     -> Chọn 'Run as Administrator' để chạy ngầm!
Khi cần tạm dừng: Chạy 'TAT_SERVICE.bat'
Khi muốn gỡ hoàn toàn: Chạy 'GO_BO_SERVICE.bat'

3. Bộ Lệnh Quản Trị Hệ Thống Qua CMD / PowerShell

Các lệnh tương tác dòng lệnh hữu ích khi bạn quản trị VPS từ xa qua SSH hoặc Terminal:

WINDOWS SERVICE MANAGEMENT COMMANDS 
# Khởi động dịch vụ WAF
net start "WAFGameService"

# Tạm dừng dịch vụ WAF
net stop "WAFGameService"

# Kiểm tra trạng thái dịch vụ WAF
sc query "WAFGameService"

# Kiểm tra các cổng TCP/UDP đang được bảo vệ
netstat -ano | findstr "LISTENING"

# Kiểm tra kết nối Web SOC Dashboard
Test-NetConnection -ComputerName 127.0.0.1 -Port 8080

4. Quản Trị Qua Web SOC Dashboard (Cổng 8080)

Giao diện Web SOC Dashboard tích hợp sẵn trong file waf-game.exe cho phép bạn theo dõi và điều khiển toàn bộ ma trận phòng thủ:

  • Overview & Traffic: Biểu đồ thời gian thực 60 giây 3 luồng (Clean RX, Outbound TX, Dropped DDoS).
  • Attack Radar: Phân loại chiến thuật tấn công và đếm số gói tin bị triệt tiêu theo từng lớp.
  • Presets & Tuning: Kích hoạt 1 chạm các chế độ Full-Stack Hybrid, Game Shield, Web Shield, Strict Lockdown.
  • Access Control: Thêm/xóa nhanh IP vào Whitelist (Danh sách trắng) và Blacklist (Danh sách cấm).
  • Port Inspector: Quét tự động danh sách các cổng TCP/UDP mở và lớp khiên tương ứng.
  • Security Logs: Luồng nhật ký bảo mật trực tiếp theo thời gian thực.
